# Features

This file provides a detailed list of all the tools available in the All-in-One Tools Platform.

## Image Tools

-   **Image Converter:** Convert images between different formats like PNG, JPG, WEBP, etc.
-   **Image Editor:** Perform basic image editing operations such as rotate, flip, and grayscale.

## PDF Tools

-   **PDF Tools:** Merge multiple PDF files into one or extract specific pages from a PDF.
-   **PDF Editor:** A comprehensive tool to perform various operations on PDF files, including merging, splitting, and rotating pages.

## Security Tools

-   **Password Generator:** Create strong, secure, and customizable passwords.
-   **JWT Token Generator:** Generate JSON Web Tokens (JWT) with a custom payload and secret key.
-   **JWT Secret Generator:** Generate a random and secure secret key for signing JWTs.
-   **URL Scanner:** Scan URLs to detect potential phishing, malware, or other security risks.

## Developer Tools

-   **JSON Formatter:** Validate, format, and minify JSON data for better readability and debugging.
-   **UUID Generator:** Generate version 4 UUIDs (Universally Unique Identifiers).
-   **Base64 Converter:** Encode and decode text or files to and from Base64 format.
-   **URL Encoder:** Encode or decode URLs to ensure they are safe to transmit over the internet.
-   **Markdown Preview:** A real-time editor to write and preview Markdown syntax.

## Text Tools

-   **Text Converter:** Perform various text manipulations like changing case, counting words, and removing duplicate lines.

## Miscellaneous

-   **QR Generator:** Create custom QR codes for any link, text, or other data.
-   **Color Tools:** A suite of tools for picking, converting, and generating color palettes.
-   **Unit Converter:** Convert between different units of measurement for length, weight, temperature, and more.
-   **Download Manager:** A tool to download videos from URLs or scrape websites for assets.
